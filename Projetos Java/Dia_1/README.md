# 🚀 Desafio 30 Dias de Fundamentos com Java

Este repositório documenta minha jornada de estudos diários e prática intensiva na linguagem **Java**, aplicando conceitos cruciais de programação, lógica, Orientação a Objetos (POO) e boas práticas de desenvolvimento de software.

## 🎯 Objetivo do Projeto
Demonstrar a evolução diária no domínio da sintaxe Java, estrutura de dados e resolução de problemas, construindo um histórico transparente de aprendizado que une minha bagagem de 10+ anos em Telecomunicações/Redes com o 5º semestre do bacharelado em Sistemas de Informação.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Java (JDK 17+)
* **IDE:** Visual Studio Code (VS Code)
* **Controle de Versão:** Git & GitHub
* **Sistema Operacional:** Windows
